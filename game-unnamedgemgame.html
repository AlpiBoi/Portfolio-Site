Unnamed Gem Game (temp name)

THIS GAME IS A W.I.P.

Find the game on my Itch.io page:

https://alpiboi.itch.io/unnamed-gem-game

A simple incremental clicker game, made with expandability as a main priority.

Current Features

  • Unity Engine
  • Heavy use of scriptable objects, for ease of expansion
  • 3 ores/gems
  • Various upgrades
  • Custom cursor
  • More ores/Gems/Upgrades can be easily added

Upcoming Features

  • More Gems and Upgrades
  • Abilities: passively destory ores using perk points from leveling up!
  • Encyclopedia: See what you have collected so far and learn about it
  • Options: options like volume,display, hide all amxed upgrades, etc.

Planned future Features

  • Exploration system: Eplore to find relics, gems, and enemies to fight
  • Combat system: defeat enemies in a bullet hell style minigame for various rewards
  • Forge system: Transform your gems into various gear and relics
  • Relic system: Grants various bonuses, from raw stats to special boosts
